# 视觉规范与素材清单（VISUAL-SPEC）

> 艾泽拉斯星命罗盘 · 设计系统说明
> 本文档描述页面的配色、字阶、边框质感与全部素材出处。所有素材均为**原创程序化生成**（CSS / 内联 SVG），未使用任何暴雪官方美术、字体或商标资源。

---

## 1. 设计基调

**史诗电影暗金**（评审锚点：aesthetic-preset-library 05 Locomotive 语境）：
深色材质底 + 金色描边 + 法术书 / 卷轴质感 + 职业专属配色。
以「暗色金属渐变、金色细描边、径向光晕」三个核心手法营造魔兽官网气质；
动效克制（进入动画 ≤ 0.34s，仅一处装饰性星环缓慢旋转），并尊重 `prefers-reduced-motion`。

## 3. 字阶与字体

系统字体栈（无网络字体请求）：
- 展示体 `--font-display`: `"Songti SC", "STSong", "Noto Serif SC", …, serif`（标题与题干；衬线带来“碑文感”）
- 正文 `--font-body`: `"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", …, sans-serif`
- 数字/代码 `--font-mono`: `"SF Mono", Menlo, Consolas, monospace`（计数、得分）

字号阶：英雄标题 `clamp(34px, 6.2vw, 64px)` · 结果职业名 `clamp(38px, 6vw, 58px)` · 区块标题 21–28px · 题干 `clamp(20px, 3vw, 26px)` · 正文 14.5–16px · 辅助 12–13.5px。字距：标题 0.06–0.16em，小标签 0.2–0.42em。

## 4. 边框与质感

- **面板**：1px 金线描边 + 顶部微光内阴影 + 深投影；四角 3px 金色铆钉（多层径向渐变绘制）。
- **按钮**：双层背景（金属渐变 + 光泽层）+ 内高光 + 悬停金色光晕与外发光。
- **英雄区**：背后一周大星环（border + 三层 box-shadow 光晕）+ 径向暗紫/余烬色斑；标题采用金色渐变文字（`background-clip:text`）+ 投影。
- **质感噪点**：内联 SVG `feTurbulence` data-URI，全站 5% 透明度叠加，模拟旧纸/金属颗粒。
- **星座图**：原创「星点连线」画法（圆点 + 线段），48×48 坐标系，主星座图内嵌于圆形底盘。
- **职业徽章**：13 组原创几何线条图形（武器/盾/法器等抽象符号），`src/ui/icons.js`，随职业色渲染。

## 6. 可访问性

- **对比度**：全部正文级组合 ≥ 4.5:1（实测 5.9–14.5:1），装饰级 ≥ 3:1（`npm run verify:contrast` 可复跑）。
- **键盘**：全部交互可键盘完成（五档按钮 `1-5` 直选、星座卡 `Enter` 选择、`←` 回退、`Tab` 遍历、弹窗 `Esc` 关闭、品牌位可回车进入）。
- **焦点可见**：统一金色 2px 轮廓（`:focus-visible`）。
- **语义**：进度条 `role="progressbar"`、选项 `aria-pressed`、装饰图形 `aria-hidden`、弹窗 `role="dialog"` + `aria-modal`、动态提示 `aria-live`。
- **动效**：`prefers-reduced-motion` 下全部动画近零时长。

## 7. 响应式

- 断点：`860px`（导航收起为汉堡菜单）、`640px`（单栏、密排、按钮全宽、星座面板上下堆叠）。
- 结果网格：`minmax(420px, 1fr)` 自适应两栏；手机单栏。
- 实测无横向滚动（1440px 桌面与 390px 手机视口，E2E 断言通过）。

## 8. 星座选择页与星座标记（v3）

- **星座选择页**：12 张星座卡网格（桌面 `repeat(auto-fill, minmax(150px, 1fr))` 自适应；≤640px 三列）。每卡含：迷你星图（复用 `zodiac.js` 星点坐标，52px 显示）、星座名（衬线、金字）、英文名、日期区间（等宽字体）、三枚关键词；悬停抬升 + 金色描边，`focus-visible` 金色 2px 轮廓。
- **答题页星座徽记** `.quiz-sign`：「✦ 星座名」金色小字，紧随模式名显示（无星座的旧会话不显示）。
- **结果页同频度** `.z-pick`：「✦ 你选择：X · 同频度 N%」；同频度四档：作答推演与所选星座完全一致 98 / 副位 90 / 同元素 80 / 其余 68。
